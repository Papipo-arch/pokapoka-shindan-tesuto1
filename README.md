# ポカポカ診断（中間発表用デモ）

大田区の銭湯への来店を促す診断Webアプリのデモです。
18問の質問に答えると「ポカポカタイプ」（8タイプ）と、おすすめ銭湯TOP3、その周辺のおすすめスポットが表示されます。

> 銭湯・周辺施設の名前や料金・営業時間・住所などは、すべてデモ用の仮データです。

## 公開URL（iPad・スマホ用）

https://papipo-arch.github.io/pokapoka-shindan-tesuto1/

（GitHub Pages を有効にすると開けるようになります）

## 起動方法（このパソコンで開く場合）

インストールは不要です。

1. Finderで `pokapoka-shindan` フォルダを開く
2. `index.html` をダブルクリック（Chrome / Safari / Edge で開きます）

ネットにつながっていなくても動きます（その場合、文字のフォントだけパソコン標準の丸ゴシックになります）。

### うまく開けないときの別の方法（ローカルサーバー）

ターミナルで次のコマンドを実行し、ブラウザで http://localhost:5180 を開きます。

```bash
python3 -m http.server 5180 --directory ~/pokapoka-shindan
```

止めるときはターミナルで `Ctrl + C`。

## 発表での操作の流れ

1. トップページ → 「無料で診断する」
2. 18問に回答（選ぶと自動で次へ。「前へ」で戻って答えを変えられます）
   - PCではキーボードの `1〜4` / `A〜D` でも選べます
3. 最後の質問で「診断結果を見る」
4. 結果ページ：タイプ → 性格分析 → ポカポカ成分グラフ → おすすめ銭湯TOP3 → シェア
5. 1位の「詳しく見る」→ 銭湯の詳細 → 「この銭湯の近くで、あなたにおすすめの場所」
6. スポットの「詳細を見る」でポップアップ表示
7. 「もう一度診断する」で最初から

時間がないときは、トップページ下の「発表用：ランダムに回答してすぐ結果を見る」で一気に結果画面へ進めます。

## ファイル構成（何をどこで変えるか）

| ファイル | 中身 |
| --- | --- |
| `js/data/questions.js` | 6つの指標と18問の質問・選択肢・加点 |
| `js/data/types.js` | 8タイプの名前・色・キャッチコピー・性格分析の文章 |

| `js/data/spots.js` | 周辺スポットのデータ |
| `js/scoring.js` | 診断の計算（タイプ判定・ランキング・スポットの順位） |
| `js/icons.js` | アイコンとイラスト（SVG） |
| `js/share.js` | シェア・コピー・画像保存 |
| `js/app.js` | 画面の表示と操作 |
| `css/style.css` | デザイン |

## 診断のしくみ

1. 各選択肢に「リラックス」「サウナ・設備」「レトロ・雰囲気」「新しい体験」「食事・街歩き」「気軽さ・アクセス」の点数が設定されています。
2. 18問の点数を合計して、6つの指標の「グラフの形」を作ります。
3. 8タイプそれぞれの理想の形と比べ、いちばん形が近いタイプを結果にします。
4. 銭湯A〜Fの特徴スコアとも形を比べ、近い順にランキングします（おすすめスコア = 形の近さを100点満点に換算）。
5. 周辺スポットは「タイプの好み」「Q13・Q17などの回答」「指標との相性」を合わせて順位を決めます。

## エラーが出たら

- まずブラウザを再読み込み（`Cmd + R`）
- 画面がおかしいときは「もう一度診断する」で最初からやり直し
- それでもだめなら、ブラウザの開発者ツール（`Cmd + Option + I`）の「Console」に赤いエラーが出ていないか確認
- データファイルを編集した後なら、カンマ `,` や `"` の付け忘れ・消し忘れがないか確認
